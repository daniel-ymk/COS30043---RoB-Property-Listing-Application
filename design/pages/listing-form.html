Dev notes · Create / edit listing (/owner/listings/new, /:id/edit) · Khant
  • Create: POST properties.php → then POST images.php?property_id= with photos[]. Edit: PUT properties.php?id= (full object), reorder PUT images.php {order:[ids]}, remove DELETE images.php?id=.
  • Upload progress from XMLHttpRequest.upload.onprogress → the bar on each new thumb. Reject wrong type / >2 MB before uploading.
  • Rent/sale switches the price suffix. The preview card updates live from the form (it's the same PropertyCard).
  • Map click sets latitude/longitude (both or neither). Edit mode: listing-form.html?id=1.
